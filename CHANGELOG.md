# Changelog

Releases are named "Self-Effects V&lt;n&gt;" (tag `v<n>`); V1 and V2 were released as Ragdoll On Command. Each section is that release's notes.

## V3 (unreleased)

- Renamed Self-Effects: the mod now applies negative effects to your own Helldiver, not just the ragdoll.
- Three keys (Effect 1 to 3), each set to an effect in Mod Options Menu: Ragdoll, Set on Fire, Stun, Gas, Bleeding, Confusion, Acid, Slowed, Poisoned, Injured Leg, Injured Arm or Injured Chest. Without Mod Options Menu the keys are Ragdoll, Rooted and Stun.
- Effect 1 keeps the key you gave the Ragdoll binding.
- Removed the delay setting.
- Fixed: another mod's declarations of the Windows functions could break the keys.

## V2 (2026-10-05)

- Added a Mod Options Menu setting: Delay After Key Press (Milliseconds), from 0 to 1000 ms (default 0).

## V1 (2026-10-04)

- First release: a Mod Bindings Menu key that ragdolls your Helldiver.
- Translated into every game language.
